# public/img — Team Water decorative art

All assets are hand-optimised inline-style SVGs. They make no external requests, contain no text, and use the colours from `/css/tokens.css`. Owner: Visuals.

| File | Size | Intended use | Alt text |
|---|---|---|---|
| `logo.svg` | ~0.9 KB | Team Water mark (a cobalt droplet with a teal wave and a navy offset shadow). 48×48 viewBox. Use it in the header next to the "Team Water" wordmark. | `alt=""` when the visible name "Team Water" sits next to it. Otherwise `alt="Team Water"`. The file also carries `role="img" aria-label="Team Water"` for inline use. |
| `favicon.svg` | ~0.6 KB | Browser tab icon: `<link rel="icon" href="/img/favicon.svg" type="image/svg+xml">`. It lightens itself under `prefers-color-scheme: dark`. | n/a |
| `wave-ribbon.svg` | ~0.7 KB | The wavy cobalt band behind the hand-lettered (Gochi Hand, white) marquee, as in reference 5. It tiles seamlessly every 400 units: `background: url(/img/wave-ribbon.svg) repeat-x center / auto 100%;` on an element about 64–96 px tall. Keep marquee text vertically centred. | Decorative: `alt=""`, or use it as a CSS background. |
| `shoreline.svg` | ~7.9 KB | A top-down band of water, lacy foam and sand with a tiny starfish, shell and pebbles (reference 1). It tiles seamlessly every 480 units: `background: url(/img/shoreline.svg) repeat-x bottom / auto 100%;` (60–120 px tall). Use it as a section divider or footer edge. | Decorative: `alt=""`. |
| `gulls.svg` | ~1.3 KB | Four white gulls with dark wingtips (reference 2). They look best over cobalt or navy (hero, ribbon, footer). A faint slate outline keeps them visible on light backgrounds. | Decorative: `alt=""`. |

| `pattern-foam.svg` | ~0.9 KB | Subtle foam bubbles for backgrounds. It tiles seamlessly: `background: var(--tw-teal-100) url(/img/pattern-foam.svg) 0 0 / 120px 120px;` and also works on cream. | Decorative (CSS background). |

## Not present: `hero-shore-1600.webp` / `hero-shore-800.webp`

The brief allowed one generated raster hero, but no WebP files were produced:

- The Higgsfield CDN (`*.cloudfront.net`) is blocked by the sandbox egress policy.
- The models that suit flat vector art need a paid plan.

For details, see `docs/VISUAL_BUDGET.md`. Build the hero from the SVGs above instead:

- `shoreline.svg` along the bottom of the hero
- `heron.svg` and `gulls.svg` as accents
- the cream `--tw-bg` background

If a hero raster is added later, save it here as `hero-shore-1600.webp` and `hero-shore-800.webp` (each under 150 KB), serve it with `srcset`, and mark it decorative with `alt=""`.
